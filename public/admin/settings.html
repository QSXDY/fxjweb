站点设置

站点信息

电话、微信、跳转链接等全局配置，修改保存后全站立即生效。

支持 SVG / PNG / WebP / JPG，SVG 最清晰
推荐 SVG（无尺寸限制）或 ≥32×32 的 PNG
支持 PNG / WebP / JPG / SVG，建议正方形 500×500 以上

导航菜单

网站顶部与移动端菜单共用这份配置。每项只需填写「链接标识」（英文小写字母、数字、短横线，如 team），前台会自动生成 #team 跳转锚点。

链接标识用途说明：① 前台锚点（自动加 #）；② 图片上传的分类文件夹（自动建目录）；③ 修改标识后，对应图片文件夹会自动改名，已插入页面的图片不受影响。
「首页」为系统固定项，无需填写，不可删除。

套餐详情弹窗数据

首页点击「查看详情」弹窗的内容。下方为 JSON 数据，格式务必保持正确（逗号、引号齐全），改错会导致弹窗恢复默认内容。一般建议用「恢复默认」再小幅修改。

首页区块（专家团队 / 服务保障）

首页三个内容区的可视化编辑：套餐入口卡、专家团队、服务保障。前台每个区域自动排布（每排 3 个），新增内容自动往后追加、超出自动换行，不会留下空位。

套餐方案入口卡：由「套餐方案」页签数据自动生成（名称 / 副标题 / 标签 / 入口卡图），无需在此重复填写；新增或停用餐线后入口卡自动增减、自动排布。

专家团队（前台每排 3 个）

「图标」为卡片左上角图形；「正文条目」每行一条；「底部标签」每行一条（如：人社部国家级证书）。成员新增后自动追加到末尾并换行。

服务保障（前台每排 3 个）

保存后前台立即生效

套餐方案（餐线二级页）

表单模式可视化编辑每条餐线的文字与图片，驱动二级页、首页入口区与导航下拉；保存后前台立即生效。高级模式可编辑原始 JSON。

实时预览（未保存，以当前表单内容为准）
结构说明：以 slug 为键的对象。slug：网址标识；name：名称；tagline/sub：主标题/副标题；hero/card：图片路径（留空显示占位）；tags：特性标签；forWhom：适用人群；stages：调理路径；shortPlans：短期体验（days/name/tag/desc/points）；tiers：三档套餐（key/name/tag/desc/img/features/modules）；enabled：是否启用。页面不展示任何金额。
